# Healthcare Appointment & Patient Portal

A professional and responsive healthcare portal for patient registration and appointment management.

### Features

* Patient Registration Form
* HTML5 Form Validation
* Doctor & Department Selection
* Appointment Scheduling
* Appointment Records Table
* Health Information
* Healthcare Services
* Responsive Bootstrap 5 Design

### Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
